# UI布局更新总结

## 更新概述
根据用户需求，对KunlunSec AI Platform进行了界面布局重构，实现了类似Cursor AI的现代化布局风格。

## 主要改进

### 1. 右侧面板显示逻辑优化
- **智能显示**: 右侧工具面板现在只在聊天对话界面显示
- **适用页面**: 主页(/)、智能体页面(/agents/*)
- **隐藏页面**: 知识库(/knowledge)、MCP工具(/models)
- **动态调整**: 根据当前路由自动显示/隐藏面板

### 2. 布局比例调整
- **左侧Activity Bar**: 保持48px宽度
- **任务列表面板**: 调整为200px（原260px）
- **右侧工具面板**: 调整为450px（用户设置）
- **中央内容区**: 弹性布局，自动适应剩余空间

### 3. 路由感知布局
```javascript
// 计算是否显示右侧面板 - 在主页和智能体页面显示
const showRightPanel = computed(() => {
  return route.path === '/' || 
         route.path === '/dashboard' || 
         route.path.startsWith('/agents/')
})
```

### 4. 用户体验优化
- **知识库页面**: 全宽度展示，无右侧面板干扰
- **MCP工具页面**: 全宽度展示，专注于配置管理
- **聊天界面**: 保持右侧工具面板，显示执行信息
- **智能体页面**: 保持右侧面板，支持工具交互

## 技术实现

### 1. 响应式计算属性
使用Vue 3的computed API实现路由感知的面板显示逻辑

### 2. CSS布局优化
- 移除不必要的`.panel-open`类样式
- 简化主工作区布局逻辑
- 保持响应式设计兼容性

### 3. 组件间通信
- 保持全局provide/inject机制
- 支持智能体页面的工具面板调用
